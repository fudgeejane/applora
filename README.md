# Applora

Applora is a job application tracking and career management web application designed to help job seekers organize and manage their job search in one place. Applora provides a centralized workspace for tracking job applications, managing resumes, monitoring interviews, viewing application analytics, and receiving career assistance.


## Main Features

* **Job Application Tracker** — Organize applications and track their status.
* **Analytics** — Monitor application activity and job search progress.
* **AI Resume Analyzer** — Review resumes and provide improvement suggestions.
* **Resume Management** — Upload and organize multiple resume versions.
* **Interview Management** — Keep track of interview schedules and details.
* **Smart Reminders** — Manage important application and interview reminders.
* **AI Career Assistant** — Get career-related guidance and assistance.


## Tech Stack

* **React.js** — Frontend framework
* **Tailwind CSS** — UI styling and responsive design
* **Vite** — Development and build tool
* **JavaScript** — Application logic
* **React Router** — Client-side routing
* **GSAP** — Animations and interactions

## Goal

The goal of Applora is to provide job seekers with a simple, organized, and efficient way to manage their entire job application process from one platform.
